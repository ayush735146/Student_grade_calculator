# Student Grade Calculator 🎓

## Description
A Python program that calculates grades for students based on their marks using predefined grading conditions[span_7](start_span)[span_7](end_span).

## Objective
The main objective of this project is to practice conditional statements (`if`, `elif`, `else`) and apply them to a simple data analysis problem by evaluating student marks[span_8](start_span)[span_8](end_span).

## Tools Used
* Python[span_9](start_span)[span_9](end_span)
* Jupyter Notebook[span_10](start_span)[span_10](end_span)

## Grading Logic
The program uses the following predefined criteria to assign grades:

* **90 to 100**: `A+`
* **80 to 89**: `A`
* **70 to 79**: `B`
* **60 to 69**: `C`
* **50 to 59**: `D`
* **Below 50**: `F (Fail)`
* **Below 0 or Above 100**: `Invalid Marks` (Error Handling)

## How to Run
1. Clone this repository.
2. Open `student_grade_calculator.ipynb` in Jupyter Notebook.
3. Run all the cells to see the output showing student names, their marks, and the assigned grades[span_11](start_span)[span_11](end_span).
